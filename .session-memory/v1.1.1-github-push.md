## KEY DECISIONS
- **Repo name `svg-tracer` chosen by user** despite my objection
  that it implies potrace-style vector outline tracing. The
  tool is a hatch generator. README has a 3-line callout
  disambiguating this on landing. Cost: organic search traffic
  will be diluted by users looking for vector tracers.
- **Package identity stays `png2svg`** — that's the import name,
  CLI command, and PyPI package. Only the GitHub repo URL changed.
- **Branch rename is `main` → `v1.0.0-release`** on GitHub default,
  so the README/CHANGELOG URLs work and the landing page shows the
  release branch.
- **6 planning/session docs untracked** — files remain on disk
  for local reference but are not in the public repo. The user
  was emphatic: "We only want to be pushing our code, not our
  planning docs."

## GH CREATION GOTCHA
- `GITHUB_PERSONAL_ACCESS_TOKEN` in env is a fine-grained PAT
  with admin on 3 specific repos (AttackLM, Boomerang-v3,
  memini-ai-dev). It does NOT have repo creation scope.
- `gh` CLI is authed with `repo` scope and CAN create repos.
- Future work: use `gh repo create` for new repos; use the
  env PAT for push/pull to existing repos.
