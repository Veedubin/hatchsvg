## VERDICT ON 4 DEFERRED ITEMS THE USER ASKED ABOUT
1. Split core.py into 6 modules — DEFER to v1.2.0. High risk, would rewrite 88 tests. Current core.py is workable, just dense.
2. Replace golden file with semantic XML comparison — DEFER to v1.2.0. Weakens the test contract. Byte-level golden has caught real drift.
3. `from __future__ import annotations` — SKIP PERMANENTLY. Non-finding. Never added. Python 3.11+ has PEP 604 natively. Linter agent recommended it as a generic 3.9→3.11 migration; not applicable.
4. Move scipy from plot to core deps — DEFER INDEFINITELY. Metadata swap with no functional impact. Current state is correct: scipy is optional and only used by plot/analysis extras. Moving it would force-install scipy on every pip install png2svg user, which is wrong.

## KEY LESSON
"Non-findings have value." 3 of 4 deferred items were genuinely non-issues. Don't be afraid to call out linter/architect recommendations as cargo cult — the user explicitly thanked me for skipping the future import.
