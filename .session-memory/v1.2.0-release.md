## WHAT SHIPPED (v1.2.0)

Six new features, 26 new tests, 0 regressions.

### 4 new CLI flags (all opt-in, default behavior unchanged)
- `--preview` — opens output SVG in default viewer post-render (stdlib webbrowser)
- `--split-layers` — writes one SVG per color layer (file_<NN>_<color>.svg)
- `--optimize-travel` — greedy nearest-neighbor layer reordering
- `--hatch-angles` — comma-separated per-layer hatch rotation (e.g. 0,45,90,135)

### 2 always-on improvements
- ViewBox normalization (integer-rounded for Cricut Design Space)
- `--help` with 5 inline examples in triple-backtick code blocks

## KEY DECISIONS
- **All new features opt-in.** Default behavior unchanged. Golden file preserved. This was a hard constraint from the spec.
- **ViewBox normalization shipped without a flag** (was a bug fix masquerading as a feature). The golden file already used integers so no test update needed.
- **`--optimize-travel` uses greedy nearest-neighbor**, not optimal TSP. O(N^2), good enough for N<100 paths, fast.
- **`--hatch-angles` applied as SVG transform**, not by recomputing hatch coordinates. Much simpler.
- **`--split-layers` re-renders each layer individually** via new `render_single_layer_svg()` helper, not by post-processing the combined SVG. Cleaner.
- **N806 errors fixed with `# noqa: N806`**, matching the pre-existing convention at core.py:934. Did NOT rename H/W throughout the file — out of scope for this release.

## PARALLEL AGENT LESSONS
1. **Spec first, then parallel.** Writing the spec took 5 min; saved 30+ min of agent confusion.
2. **Sub-agents can write tests against uncommitted working-tree code.** The tester and writer both saw the coder's implementation in the FS even though it wasn't committed yet. This is fine — the orchestrator commits at the end.
3. **Max-steps is a real failure mode.** The coder hit it and never committed. Solution: the orchestrator always checks `git log` after each agent returns, and commits any uncommitted work.
4. **Each agent should commit its own work** to make failure recovery easier. The coder didn't follow this convention; future specs should make it explicit.
